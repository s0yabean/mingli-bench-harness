# Newsletter Digest Rubric

Grade the file at `/mnt/session/outputs/newsletter-digest.md` against every
criterion below. Each is independently gradeable -- do not average a vague
overall impression.

1. The file exists at `/mnt/session/outputs/newsletter-digest.md` and is
   valid markdown.
2. It contains between 10 and 15 links, inclusive -- not fewer, not more.
3. Every entry includes: a title, the source name, a working URL, and one
   sentence explaining why it fits the audience described in the system
   prompt.
4. No more than 3 links share the same source domain.
5. Every entry is genuinely recent or newly notable -- not evergreen
   reference material with no news hook, unless explicitly framed as a
   notable resource rather than "news."
6. Zero entries are generic horoscope content, deterministic fortune-telling,
   or otherwise contradict the brand stance of "probabilistic not
   deterministic, mirror not crystal ball, navigation system not identity
   prison."
7. Entries are grouped loosely by theme (AI x pattern intelligence,
   decision science, founder/career decisions, symbolic systems commentary)
   -- rigid or forced categorization is not required, but entries should not
   be in arbitrary/random order.
8. The digest reflects the positioning found in
   `docs/product_decisions/seo-keyword-targets.md` and the About page in the
   mounted repo -- if the agent did not appear to consult these before
   researching, this criterion fails.
